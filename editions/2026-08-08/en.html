This upgrade brings canonical, fully reserved USDC directly onto X Layer, eliminating bridge risk for users and improving compliance with EU stablecoin regulation. It is a material market-structure improvement for OKX's L2 ecosystem and its users. The integration automatically routes exchange deposits and withdrawals on X Layer to settle in native USDC, which is 1:1 redeemable for USD and MiCA-compliant. The previous bridged version, USDC_Bridged, is no longer used for these flows.

Background, discussion, and references

Background

Native USDC is issued directly by Circle and is backed 1:1 by US dollars, whereas bridged USDC is a representation created on another blockchain via a bridge contract, which introduces additional smart-contract risk. X Layer is an EVM-compatible Layer 2 network built by OKX using the Polygon CDK and AggLayer technology. MiCA is the European Union's comprehensive regulatory framework for crypto-assets, which includes specific requirements for stablecoin issuers.
